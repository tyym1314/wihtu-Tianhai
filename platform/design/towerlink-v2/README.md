使用内置 imagegen 生成，供美术方向确认；尚未替换线上界面。

完整生成提示词：[prompt.txt](prompt.txt)。

画面方向：翡翠绿与珊瑚红对抗、象牙石材与香槟金、浮空王城、可点击的立体城堡、清晰的能量连线。当前示意为双人对局；三人和四人需要在同一套资产下分别排版。

实现建议：用 Blender 制作和烘焙可分层的城堡、岛屿和地表素材，以图集呈现；连线、选中光圈、得分反馈与小范围粒子动态绘制。先验证动作和弱网下的帧预算，再增加环境动画。设计图是静帧，不能证明动效和设备帧率。

玩法不变：从己方塔连向相邻中立塔，按服务端结果占领与计分。图中的塔值、线路与状态布局是美术示意，制作时绑定真实地图数据，不采用整张设计图覆盖交互。
