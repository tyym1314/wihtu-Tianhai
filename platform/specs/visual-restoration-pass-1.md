## 工具判断

**Blender 值得引入，特别是竞速角色和高尔夫场景。** 它承担模型、材质、灯光烘焙、角色绑定和动作制作；Three.js 保持为现有运行时。固定机位的棋盘类可使用 Blender 烘焙/预渲染资产和实时棋子组合，不必让整套 UI 全部变成实时 3D。

三消/老虎可以使用专业的分层 2D 骨骼动画，或 Blender 输出的连续透明动画图集。当前三消只有三个一致角色姿态和 CSS 动作，并非已经交付骨骼动画。UI 的精确尺寸和状态需要 Figma/SVG 尺寸稿。没有迁移 Unity 的必要。工具功能依据见 [还原规格及官方文档链接](visual-restoration-v2.md)。

**本轮没有安装或使用 Blender，没有交付 `.blend`/GLB 角色包。** 静态设计的 MOMENT 屏不能证明动作节奏已还原，还需要逐段动作分镜与录像核对。

## 素材与体积

内置 image_gen 生成原稿风格的狐狸、宝石、虚构默认肖像和十主题奖杯，原始文件及完整提示词保存在 [prompts.json](../arena/public/assets/restoration/prompts.json)。运行时使用 `fox-poses-v2.webp`、`gems-v2.webp`、`player-portraits-v2.webp`、`trophies-v2.webp`。其 PNG 原件保留，编码记录在 [encoding.json](../arena/public/assets/restoration/encoding.json)。四张合计 9,107,005 字节减至 1,568,504 字节；仅格式编码，无尺寸变更。合作方提供头像时优先使用合作方图片。

新增飞镖/八球环境与 Jackaroo/Domino 环境的提示词、源图和引用分别保存在游戏自身 assets/provenance 或 README 中。新图是独立素材，不用整张设计图遮盖可玩界面。
