# 移动游戏质量标准 v1

建立日期：2026-09-28。适用：现有 11 款竞技游戏、Thunder、Tiger；主要入口 `/demo/`。这份标准先于本轮实现冻结，任何调低门槛都必须留下理由和旧值，不能为了让报告变绿而修改。机器门槛在 `mobile-quality-v1.json`。

## 验收环境与结论

- 主设备：用户的 iPhone 15 Pro / Safari / Wi-Fi，记录 iOS、Safari、屏幕刷新状态、低电量模式、网络 RTT、下载速率、起始温度状态。参考 viewport 393×852 CSS px；同时检查 360×800、390×844、430×932 与横竖屏切换。
- 受控 Wi-Fi：下载 20 Mbps、上传 5 Mbps、RTT 50ms；弱网：下载 4 Mbps、上传 1 Mbps、RTT 150ms，另测 10 秒断网。它们是本项目测试条件，不是“所有 Wi-Fi”的定义。
- Chrome 和桌面 WebKit 是工程回归环境，分别标记；CPU 限速不是某款 iPhone 的仿真。浏览器缺失的指标记 `unmeasured`，不能填 0。脚本缺证据记 `insufficient`，不能判通过。
- 每款冷入口 5 次（独立缓存、连接条件明确），热入口 5 次（同浏览器保留缓存），报告中位数、P95、全部原始样本。5 次的 P95 按 nearest-rank 等于最慢值，不假装统计置信充分。
- 工程采样至少 60 秒且至少一次真实动作；完整局、最复杂中盘、首转/大特效、断线恢复分别覆盖。真机每款至少 15 分钟或 3 个完整局中较长者，至少 30 次有效操作。性能测量串行执行。
- `engineering-pass` 只代表工具可验证门槛；只有真实设备、内容可玩性、服务容量全部通过才能写 `mobile-release-pass`。本标准不代替钱包、概率数学、合规等生产准入。

## A. 加载与运行（所有 13 款）

| 编号 | 必须达到的门槛 | 测量口径 |
| --- | --- | --- |
| LOAD-01 | 冷入口 P95 ≤5,000ms；热入口 P95 ≤2,500ms；弱网冷入口 ≤10,000ms | 从用户点选游戏至必要画面完整且首个合法操作能发出。另列认证、资源、场景准备、房间往返、规则倒计时，不把等对手算客户端慢，也不通过提前放开按钮假装加载结束 |
| LOAD-02 | 反馈 ≤100ms；超过1秒有明确加载状态；失败可重试/返回 | 第一帧反馈和最终可玩是两个指标。禁止假进度、无反馈死等；关键资源失败不能悄悄显示空场景 |
| LOAD-03 | 每款首局关键静态资源压缩传输 ≤3MiB；任一关键图片 ≤768KiB；无重复下载同图 | 网络真实 encoded bytes，API 与静态资源分开；同一缓存资源不得计作两次传输；超预算须有逐资源理由并保持未通过 |
| FRAME-01 | 前台活动采样 P95帧间隔 ≤20ms，P99 ≤34ms，超过50ms占比 ≤0.5%，最大 ≤100ms | 至少60秒；不合并加载、操作、演出、稳定期；加载长帧仍单列。持续运动需要位移/时钟检查，RAF通过不能掩盖角色周期停走 |
| FRAME-02 | 不允许正常游戏中可复现的 ≥100ms 卡顿；后台不持续渲染 | 查首个操作、首次音频/着色器、场景切换、大粒子、最复杂中盘；后台/系统弹窗帧不悄悄删掉，单独分类 |
| INPUT-01 | 本地可见响应 P95 ≤100ms；操作请求派发 P95 ≤100ms | 从可信手势完成到可见反馈/网络派发；服务确认另列，不用“等待轮到我”替代输入延迟 |
| NET-01 | 受控 Wi-Fi 动作确认 P95 ≤300ms；弱网 ≤800ms | 发出请求到权威确认；服务器内部耗时单列。正常状态轮询快照压缩后 ≤64KiB，无变化时不得反复传输大静态动作集合 |
| LIFE-01 | 连续进入/退出同游戏10次无未取消RAF、监听器、计时器、decoder worker或存活WebGL场景累积 | 记录对象/资源计数、基线与第10次；可读取堆时记录强制GC后趋势（最后3次相对稳定基线≤15%），不可读取时不能声称堆无泄漏 |
| REL-01 | 零页面异常、关键资源错误、重复动作/扣款；断网/后台恢复后状态一致 | 双指、pointercancel、失去捕获、帮助弹层、切后台、回合改变、超时重试；取消0请求，有效手势恰好1请求；结算和返回必须完整 |

低功耗/旧设备如需30fps方案，必须显式记录并单独验收，不可拿它冲抵主设备60fps目标。原始画质不能为了跑分无说明地严重降低。

## B. 手机操作与清晰度

- 普通主要按钮至少44×44 CSS px；重要小棋子/牌必须有同功能的大按钮或放大选择。小目标例外需列位置、间距和原因，不能只扩大看不见且相互重叠的触区。
- 手势必须有即时方向/目标/力度预览，松手提交；指针取消、多指、后台、过期回合不会误提交。触控区域不触发页面滚动/文本选择，页面其他区域仍正常滚动。
- 消消乐方向滑动交换，同时保留点击两格；竞速左右换道、上跳、下铲且提示明确；高尔夫/保龄球/飞镖/弹盘/八球能用单指完成整局。
- 占塔塔体不能遮挡路线、兵数和目标。拖线添加、重复连线撤单路；全撤仅作为所选塔的次级管理操作，说明“已派出的兵继续前进”。升级需明示成本与确认。
- 首屏、HUD、弹层、结算在四种宽度无横向溢出、遮挡主控或安全区；色彩之外还用数字/形状区分阵营。

## C. 规则与内容深度

这些数量是本项目的首轮最低内容预算，不是业内认证。内容相同而仅镜像、改色、改名不能重复计数；可解不等于好玩，必须保留人类测试关口。

| 游戏组 | 内容门槛与验证 |
| --- | --- |
| 沙丘竞速 | 至少6条障碍组合/节奏实质不同且确定可完成的路线，覆盖换道、跳跃、滑铲组合；至少3档挑战节奏；同局所有玩家同路线/种子，重连不换路线；自动合法动作通关与不操作对照，不得生成无解连续障碍 |
| 消消乐 | 至少3种有不同决策目标的对局配置（积分/指定宝石/特殊消除等），目标、进度、胜负在UI清楚可见；同局起点和补充序列公平，固定种子可重放；每种有合法完成样例、无步可走恢复、特殊组合/结束边界覆盖 |
| 高尔夫 | 至少9洞、3档难度，障碍或线路实质不同；每洞至少一条合法完赛解、角度/力度差异影响成绩，不允许默认连续点按无脑全洞一杆；模型与权威碰撞边界对应 |
| 连线占塔 | 保留12课的递进目标和主动AI，每课有真实成功轨迹及闲置失败对照；6张竞技图至少覆盖3种拓扑战术（抢中/分路/防线），相同座位条件可比较；胜负、撤线、升级规则无歧义。自动胜率只是筛查，不替代人类平衡 |
| 保龄球 | 默认输入不得稳定全中；合法精准口袋球可全中；偏角可落沟；镜像公平偏差有量化证据，不用隐藏随机惩罚制造难度 |
| Carrom/八球/飞镖/Ludo/Jackaroo/多米诺 | 用完整规则、关键中盘、回合边界、手机可操作性与教学验收，不机械增加关卡；合法选项不因优化被删减 |
| Thunder/Tiger | 冷首转、连转、大演出、后台/断网恢复、展示ACK、返回完整；性能优化保持原权威结果及音频/演出含义，不改变数学模型冒充内容升级 |

人类可玩性：至少5名非开发试玩者，每人覆盖入门/中段/困难内容；记录误操作、规则理解、关卡通过时间/失败原因。存在必胜漏洞、靠背同一关、难度跳崖或读不懂操作，均不得写内容通过。

## D. 服务端与交付

- 独立测试环境100并发真实游戏会话混合压测15分钟，禁止未经隔离在生产制造高负载；API P95内部处理≤100ms、P99≤250ms，错误率<0.1%，事件循环P99≤50ms，CPU持续<70%。物理出球单列耗时和并发，不用健康接口代替。
- 记录版本、源码/资源哈希、设备、网络、测量脚本、完整样本和失败记录。缓存/资源优化必须有原始结果对照，测试币房间/周期全部结清并读回。
- 修改规则/内容需版本固定与旧状态恢复；不得修改已受理结果。性能改动先定向回归，再完整后端/构建校验，最后公网实际启动、动作、结算/返回核验。
- 发布清单逐款标记 `pass / fail / insufficient / unmeasured`，发现未达标就保留，不用总体平均掩盖单款失败。

## 标准依据

60Hz每帧约16.7ms，应用可用的工作预算还要留给浏览器；本项目20/34ms分位数和卡顿比例是工程验收目标。[web.dev 渲染性能](https://web.dev/articles/rendering-performance)

网页INP的good界线是200ms；游戏局部操作采用更严格100ms目标。主线程任务超过50ms会阻塞交互，因此同时查长任务和实际帧间隔。[INP](https://web.dev/articles/inp)、[长任务](https://web.dev/articles/optimize-long-tasks)

WCAG2.2最低目标尺寸条款是24px且有间距等例外，增强条款为44px。本项目主控采用44px，不把它误称全部WCAG最低要求。[W3C目标尺寸](https://www.w3.org/TR/WCAG22/#target-size-enhanced)

后台避免计时器、网络和渲染唤醒，同时恢复时重新对齐状态。[WebKit能耗指导](https://webkit.org/blog/8970/how-web-content-can-affect-power-usage/)
