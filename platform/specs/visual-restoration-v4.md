# 光照、动作与原稿布局：继续还原

入口：[原稿 / 最新画面 / 本轮前后 / 实际录像](http://127.0.0.1:8795/design-review/index.html#run)。在“本轮前后”中，左侧是上一轮真实截图，右侧是最新游戏。原设计图仍完整保留。

## 本轮实现

- **竞速动作**：四角色分别制作 4×2、共 8 帧的跑步图集，替换原来的四帧。正常 8 m/s 时按距离推进约 14.5 次姿势变化/秒，渲染器持续按实际投影距离采样，消除 HTTP 快照之间动画暂停的问题。加入跳跃伸展、滑行压低、落地回弹和受击衰减；脚下影子留在地面并随离地高度变淡、缩小。姿势动画不更改角色位置、碰撞或胜负。
- **竞速界面**：将分散的名次、时间与奖池重组为原稿式右侧信息栏，四个头像下方共用实际进度线。顶部占高从约 220 px 减至 153 px（390 视口）；三个真实移动控制收为两主按钮之间的 44 px 圆形按钮，不用空聊天/语音图标代替可操作控件。
- **竞速场景**：为实际缺口增加向下的砂岩砌块断面与存续车道侧壁。缺口、可行走面与障碍仍使用同一份关卡数据。
- **高尔夫**：真实重建石岸与弧形棕榈叶、加入垂藤；改进石材和草地的纹理重复，加入湿石脚、近岸浅水渐变与细波。调整暖日光和冷阴影，实际重烘焙三洞接触阴影。
- **保龄球**：重新处理准备镜头、连续侧柱、顶棚灯槽及嵌入式后墙灯牌，恢复原稿场馆纵深。增加低强度局部霓虹柔光，使用独立输出变换保留色彩与球道反射；A/B 对比后降低到 0.10 强度，避免把墙面和木地板照白。球、球瓶及真实轨迹保持原有尺寸与物理。
- **飞镖**：准备姿势使用独立近端透视模型素材，扩大可辨识尾翼和金属杆。实际飞行、命中仍按镖尖与真实落点定位。
- **Carrom**：底部主控制层调整为深绿瞄准长槽与雕花 striker 滑块，保留真实置位、瞄准、力度和出杆操作。

## 制作资产

本轮竞速四张原 PNG 和运行 WebP 位于 `arena/run/assets/atlases/run-{fox,cat,bear,rabbit}-v4.*`。使用内置 image_gen，完整公共提示词、各角色说明和源路径见 `run-cycle-v4-provenance.json`。PNG 保留原透明通道，WebP 仅做格式压缩；原四帧资产保留。

高尔夫、保龄球及飞镖的 Blender 源、执行脚本和美术验证记录保留在各游戏目录。竞速仍是高精帧序列置于实时三维赛道中的 2.5D 角色；没有将其描述为实时毛发模型。
