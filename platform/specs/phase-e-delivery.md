# 阶段 E 本地交付记录

2026-09-19。八球、保龄球、沙丘竞速已接入 OASIS 本地平台，累计 **10 款竞技 + 2 款概率**。本记录确认本地实现与验证范围，不作为生产发布或最终美术验收。

## 本次新增

| 游戏 | 玩法与表现 | 人数 |

| 八球对决 | 六袋球桌、瞄准、力度、旋转、自由球放置、黑八叫袋；Canvas 2.5D 与真实轨迹回放 | 2 |
| 保龄球对决 | Three.js 3D 球道、球瓶刚体碰撞、跟球镜头、全中/补中特效；3 个计分局及末局补投 | 2 / 3 / 4 |
| 沙丘竞速 | Three.js 沙漠赛道与活动角色、左右变道、跳跃、滑铲、护盾、加速和检查点重生 | 2 / 3 / 4 |

三款均有独立大厅、音乐、操作音效、静音与结算页；BOT 仅限标记清楚的免费练习。原来九款保留入口。后台十款竞技游戏均可切换查看实玩截图、设计参考与实际录屏；录屏无音轨，音频另行检查。

## 验证结果

- **后端 289/289 通过**：规则、数学、钱包、PostgreSQL 集成、API、幂等、断线/超时及恢复。报告：`review/phase-e/backend-report.txt`。
- 静态契约检查通过：12 个游戏、18 条目标接口、40 个 schemas、508 处本地引用及 HMAC 固定向量。该检查不代表所有生产目标接口已实现。
- 三款真实平台启动 → 免费练习 → 实际输入 → 退出 → 余额不变通过。360×800、390×844、430×932 无横向溢出；Three.js 两款实际 WebGL context 成功；浏览器异常和资源加载失败均为 0。
- WebAudio 三款均测得非零信号，静音后 RMS 为 0。此项确认信号与开关，不代替人耳音质验收。
- 竞速左移、右移、跳跃、滑铲均确认服务器 `inputNo`、后续 `appliedInputNo` 和对应事件；没有仅以请求成功代替动作生效。
- 后台十款竞技截图、设计图、录像切换与播放/拖动检查通过；录像尺寸 390×844。证据：`review/phase-e/gallery-validation.json`。

主 UI 报告为 `review/phase-e/ui-validation.json`；竞速补充取景报告为 `ui-validation-partial.json`。独立游戏 QA、物理矩阵和截图分别在 `arena/pool/qa/`、`arena/bowling/review/`、`arena/run/review/`。

保龄球 **106 组合法输入、0 个物理超时故障**，包括参数角点和偏心投球；独立规则 19 项通过。八球独立规则 22 项、竞速 27 项通过。有限样本不代表穷尽全部输入或设备。

## 多人钱包实测

专用 `QA UI` App 的参考钱包，本次冻结服务费为 5%，每人入场 100 测试金币。不同测试账号实际加入、准备、操作，随后其余参与者主动退出，验证剩余玩家获胜的结算路径：

| 游戏 | 玩家数 | 总奖池 | 平台费 | 剩余玩家到账（含本金） |
|---|---:|---:|---:|---:|
| 八球 | 2 | 200 | 10 | 190 |
| 保龄球 | 3 | 300 | 15 | 285 |
| 竞速 | 4 | 400 | 20 | 380 |

这三次浏览器房间确认的是入场、动作、个人退出与钱包结算路径；自然完赛规则另外由引擎和平台集成测试覆盖。UI 脚本按房间实际冻结费率计算，可使用其他已支持的 App 费率，无需强制 5%。

数据库读回确认：三局 `SETTLED`、局内余额归零、结果 hash 相同；捕获和结算各自账本守恒，玩家派奖和费用匹配。三场主练习与一场竞速补充取景均没有钱包局单或钱包命令；验证结束没有遗留活动房间。证据：`review/phase-e/wallet-readback.json`，可用 `node scripts/review-phase-e-wallet.mjs` 重查。

## 升级与修复

- 旧默认九款授权一次性升为十二款，自定义授权不改。新建 App 显式保存全部默认授权，修复返回十二款但数据库仍写入九款的遗漏。
- 主环境升级时读回确认 4 个已有 App、16 个钱包用户、管理员与本地凭证均保留。其后专用 QA 用户按上述实测正常产生测试币变动。
- BOT 决策前先推进权威时钟，避免在已结束回合提交过期动作导致整局故障。
- 修复高尔夫末洞和保龄球末局的第三次准备超时被误当作有效完赛的问题；已合法完成的成绩继续保留。包含漏洞重现与多人同刻超时的回归用例。
- Thunder / Tiger 共 23 个原源码文件 SHA-256 不变，8787 / 8790 均返回 200。旧账号继续使用。证据：`preservation.json`、`original-source-check.json`。

## 接入与当前边界

从后台“开发者中心”进入[阶段 E 接入教程](phase-e-local-integration.md)。新增三款沿用服务端 HMAC、一次性启动码、同源 Web 宿主握手与参考钱包；合作方无须自行提交游戏结果。

当前端口：管理台 8795、平台 API 8797、参考钱包 8798、独立开发数据库 5487。前端与竞技构建通过；保龄球依赖固定在根 `package-lock.json`，使用 `npm ci` 安装。新画面为原创程序几何、Canvas/SVG 与程序音频，开源许可见 `arena/ASSETS.md`。

仍待后续阶段：Android/iOS 真机 WebView 与触控性能验收、最终画质/动效审查、跨域宿主与原生桥、独立外部钱包接入、自助验收流程、合作方权限、生产部署、实时网关、告警及并发压测。现有原型不承诺已达到 PG 商业品质。

保龄球当前 60 Hz 同步刚体求解，本机 106 样本 CPU 中位 125 ms、P95 281 ms、最大 513 ms，单个四人公开视图最大 70,944 字节。同步求解可能拖慢其他房间；生产前需物理工作池与队列隔离。竞速的 150 ms 串行轮询间隔不是网络延迟承诺。
