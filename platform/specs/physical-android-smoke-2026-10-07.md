12 款首次完整脚本报告及三消重测均记录原生返回、单屏、同源网络，未记录 JS 页面异常或静态资源 4xx；三消首轮失败报告和 Run 首轮失败报告也未记录此类异常。三消与 Run 的首轮失败均保留为可见缺陷线索。短帧样本只覆盖约 1.8 秒，除飞镖外记录的 RAF P95 间隔为 8.4 ms；其范围不足以反驳用户报告的 iPhone Safari 整场卡顿，也未覆盖高峰服务器容量、长局内存与重连。

飞镖当前界面每约 50 ms 触发一次整页 React 提交；本地 8 秒试验把提交数从 198 降到 72，但受控浏览器 RAF P95 仍约 16.7 ms。因未证明该改动能改善实体 WebView 的 24.9 ms 短样本，试验代码已撤回。下一步应在实体 WebView 记录更长的主线程及 GPU/raster trace 后再定优化点。

Run 在这台实体 Android WebView 上追加了前台 60,009 ms 的持续采样：7,206 次 RAF，间隔 P50 8.3 ms、P95/P99 8.4 ms、最大 16.7 ms；超过 33.4/50/100 ms 的间隔均为 0，权威轨道 tick 从 225 推进到 3812，练习房结束时仍为 `active`，WebGL2 上下文未丢失，实体系统截屏可见完整场景。该结果仅说明这台 Android 和公开旧版的 RAF 调度在这段时间平稳；它不测量用户 iPhone Safari 的掉帧，也不能单独证明 GPU 合成、触控延迟或 13 款正式玩法达标。原始记录仍保存在上述本地目录的 `reports/run-long/`。

为排除“RAF 在跑但场景不更新”，又在一局内的 0/5/10 秒比对：权威房间 tick 与 WebView 场景 tick 逐次同为 195/660/1081，输入就绪均为 `true`，自己 DOM 距离约 19/30/74 m（服务端约 19.73/30/74.4 m），对手距离也推进，三张实体系统截屏呈现角色和赛道位置变化。最初记录中的 `tick=0` 与输入未就绪是 60 秒采样**开始之前**的瞬时诊断，不能解释为整场停在初始画面；复核证据位于 `reports/run-checkpoints/`。

下一道门禁是本地候选在实体 Android WebView 和用户 iPhone 15 Pro Safari 上各完成逐款真实整局、至少 60 秒活动帧、冷/热/弱网加载、进退/恢复以及服务端结算/退款读回；公开旧版的单动作成功不能替代这些项目。

## 本地候选版追加检查（与上述公网旧版分开）

同一台 Xiaomi 上经 ADB reverse 打开的是全新隔离服务的 `localhost` 候选版，使用手机 **Chrome**，不是公开 APK 的 WebView。修复后构建标识为 `71879b23701c08bf5620ee43447c32e1e14e9f8596a6a16ebf12513146091f46`，arena 构建树 SHA256 前缀为 `45d1551e`。自动化用 CDP 向实体 Chrome 注入触摸事件，因此可验证浏览器触摸路径、UI 动作及服务端应答，不能证明真人手指的误触率或手感。

Run 图集预上传候选版单次冷打开到可操作 4.55 秒，注入 Jump 后 HTTP 200、个人序号 0→1；60,008 ms 前台记录约 3,600 帧，RAF 间隔 P95 16.7 ms、P99 16.8 ms、最大 33.4 ms、超过 33.4 ms 为 0，采样期 Long Task 为 0。跳/落地/碰撞/落水/恢复/滑铲图集均出现，WebGL 上下文未丢失；退出重进 4.12 秒可操作。三消真实 36 格棋盘注入交换返回 HTTP 200、序号 0→1，412×794 活跃视口中页面同高。

修复后同一候选构建的 13/13 款均通过**一次合法动作或一次转动加结果 ACK**：TowerLink 注入拖线后服务端形成持续路线及行军单位，Darts 注入上拖完成投镖，Match 完成交换；Domino 本次是合法摸牌、Jackaroo 是换牌、Bowling 仅一次投球，不代表中盘规则、完整局或“必中”问题已经验收。矩阵的两条 observer closed 是测试监听器在导航时关闭的竞态记录，并非页面 JS 异常；关键静态资源 4xx 为 0。隔离终检中 14 间练习房全部 `cancelled`、两次概率回合 `SETTLED`、`active_users=0`、`pending_presentations=0`，随后临时数据库、服务、ADB 映射和候选 Chrome 标签均已清理。含原始构建哈希、逐款请求和截图的本地记录为 `platform/review/physical-android-20261007/CANDIDATE.md`，该目录不上传。
