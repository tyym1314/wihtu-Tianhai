## 本次实现

| 游戏 | 实际交互与演出 | 模式 |
|---|---|---|
| Carrom | 可拖动击子与基线位置、点按瞄准、力度控制；服务端确定性物理轨迹、碰撞/进袋、皇后覆盖、粒子和音效；原创翡翠宫廷背景 + Canvas 木艺棋盘 | 2 人 / 4 人对座 2v2 |
| 飞镖 | 靶面拖动与释放手势、飞行/命中/爆分反馈、实际 SVG 飞镖库存；标准靶区与共享手势计算 | 双人 301 直出，等轮判定 |
| Ludo | 揭骰、选择棋子、路线高亮、逐格移动、吃子/进家反馈；皇家 SVG 棋盘 | 2 / 4 人，每人双棋子 |
| Jackaroo | 暗传牌、选择牌效/弹珠、换位、分段组合完整拆 7；木纹棋盘、玻璃质感弹珠、私有手牌与公共动作演出 | 固定四人，对座 2v2 |
| 多米诺 | 手牌选择、左右端接牌、抽到首张可出牌、过牌、落牌动画及长牌链；深蓝象牙牌桌 | 2 / 4 人个人赛 |

这五款采用 Canvas/SVG/CSS 的 2D / 2.5D 表现；高尔夫继续使用真正的 Three.js 3D。游戏场景并非整张设计图铺底的假交互。当前未宣称视觉与动效已达到最终设计验收或超过任何商业厂商。

各游戏使用不同的程序化背景旋律与动作音效，用户操作后解锁 WebAudio。页面隐藏时停止声音，静音会停止当前声部。竞技组件按需加载，进入 Carrom 等桌游无需先加载高尔夫的 Three.js 包。Carrom 场景图仅作格式优化，WebP 为 227,192 bytes，原创 PNG 与生成说明保留。

## 平台与结算

- 多 App 目录与授权、新会话、好友房、免费 BOT 练习、动作序号与原请求重试统一接入现有服务。
- Carrom 四人和 Jackaroo 的团队在扣币前公开冻结；随机座位保留同队对座。胜队成员同名次、均分净奖池。
- 四人各入场 100 币、费率 5% 时，服务费为 20 币，胜队两人各到账 190 币（含本金）。个人赛与团队有效并列按冻结规则平分；作废不收服务费。
- 同 tick 的个人退出、心跳断开与第三次回合超时先合并裁决，再固定结果，避免先处理的一方决定赢家。
- 钱包成功回执核对完整且唯一的参与者/派奖集合、冻结团队与条款、总金额、结果摘要和操作号。异常回执保持待确认，查回原交易后恢复，不另建扣款或派彩。
- 新 App 默认开放 9 款；阶段 D 迁移只扩展未改过的默认授权集合，保留自定义授权、管理员凭据、会话、余额、应用费用和已有局单。

合作方本地联调文档见[阶段 D 接入教程](phase-d-local-integration.md)，通用规范继续见[接入指南](integration-guide.md)、[钱包协议](wallet-protocol.md)和 [OpenAPI](openapi.json)。生产自接入、原生 WebView 桥接及独立合作方部署仍须后续完成。

## 运行与下一阶段

竞技前端构建 `npm run build:arena`，管理台构建 `npm run build`，服务端运行 `npm run server`，开发管理台运行 `npm run dev`。本机端口为平台 8795、API 8797、参考钱包 8798、PostgreSQL 5487。当前只完成本机运行与浏览器手机尺寸验证。

下一批为八球、保龄球、沙丘竞速。全部游戏正式上线前，仍需真实 Android/iOS WebView、跨区域弱网与并发负载、最终视觉/动效和声音审阅、完整合作方自接入以及生产部署验收。
