# 阶段 C · 三消与高尔夫本地可玩样板

日期：2026-09-18。范围为已确认计划中的两个竞技质量样板、公共多人基础与平台接入；不代表 12 款全部完成或正式生产验收。

## 可以直接试玩

打开管理平台 http://127.0.0.1:8795/#/partners，在「启动沙箱第一局」选择「三消对战」或「绿洲高尔夫」，点击「打开沙箱游戏」。

- 先看画面和操作：在游戏内选择免费练习。支持 2/3/4 席，BOT 明确标识，余额不变，离开立即结束。
- 多人联调：同一应用依次打开 demo_player、demo_player_2（亦有 _3、_4），一方创建好友房，另一方输入房间码加入，各自确认规则准备后开局。
- 平台「规则与收益」可保存应用级 3/5/8/10% 服务费，创建房间时冻结条款；现有房间不随配置变更。
- 原雷霆王座和虎虎生财保留，平台仍可启动两款概率游戏；原独立演示 8787、8790 未改。

## 本轮实现

三消：6×6 真正可操作的宝石棋盘、相同初始盘面/补牌流、90 秒计分、条纹/炸弹/彩球、逐波连锁、交换回弹/消除/下落/粒子、原创紫晶宫殿和耳廓狐分层动画。采用 SVG/DOM 渲染；角色不是完整 3D 骨骼模型。

高尔夫：三洞程序化 Three.js 真 3D 球场、绿松石水面、砂岩浮岛、棕榈/旗帜动画、拖动/点按瞄准、力度条、球轨迹与入洞反馈。服务器与画面共用关卡几何；固定步长碰撞、超时/落水罚杆、封顶与总杆数规则。

公共：好友房、2/3/4 人、同应用隔离、个人重连、服务重启恢复、真实冻结/全员捕获/结算、取消退款、固定结果后原号恢复、后台局单/钱包操作查询、WebAudio 背景乐及事件音效、静音与后台切换处理。

## 验证证据

- [付费双人浏览器联调](../review/phase-c/ui-validation.json)：三消通过真实 UI 交换宝石并跑完实际 90 秒，两个玩家最终 SETTLED；高尔夫通过真实 UI 发起击球、对手主动弃权后 SETTLED。两个案例各 100 币入场、5% 服务费，胜者毛到账 190 币。
- [免费练习与声音](../review/phase-c/practice-validation.json)：两款 4 人练习、360/430 手机视口、背景音乐实际音频信号、静音信号归零、立即退出与钱包不变均通过。通过界面保存 8% 费率后读回，测试结束恢复原配置。三消落库后丢失动作响应，UI 沿用原号重试只受理一次。
- [后端回归](../review/phase-c/backend-report.txt)：81/81 通过，连续两次全量复跑。覆盖规则、钱包、幂等、房间状态、跨应用、并列、断线、恢复和故障注入。PvP 使用独立临时 PostgreSQL 数据库，恢复子进程显式连接同一测试库，测试后数据库已删除。
- [三消独立浏览器检查](../arena/match/review/)：点击/拖拽、非法回弹、36 格补齐、轮询期间演出、移动布局与三语言。
- [高尔夫独立检查](../arena/golf/qa/browser-report.json)：三个球洞与英/中/阿语视口；UI 点击一杆入洞。引擎另覆盖合法动作完成三洞。
- [既有两款回归](../review/phase-b/ui-review.json)：真实启动、spin/ack、主钱包接入通过；13 项平台交互检查、五个标识清楚的协议演示、七页移动布局通过，无页面错误。
- [本地文件访问边界](../review/phase-c/local-file-boundaries.json)：修复 Vite 开发服务能够读取 `.local` 凭证文件的配置问题；凭证、主密钥、后端及测试源文件的普通/raw/@fs 请求均被拒绝，公开文档与游戏资源仍可读取。只做过 HTTP 状态探测，未在报告输出凭证。
- [原游戏源文件核对](../review/phase-c/original-source-check.json)：23 个源文件哈希不变。

以上浏览器检查运行于桌面 Chrome 的手机尺寸视口。不是物理 Android/iOS WebView、弱网或低端机帧率验收；声音验证了信号与开关，仍需实际设备听感审核。高尔夫付费双人浏览器案例通过弃权结束，没有冒充三洞完整真人比赛。
