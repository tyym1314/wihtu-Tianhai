# 阶段 A 交付记录

用户已确认完整建设方案；本次交付对应阶段 A：平台关键页面、玩法与资源规格、接入/钱包契约、技术预研。12 款游戏的生产开发和正式平台服务仍属于后续阶段。

**可浏览设计。** 本机地址 http://127.0.0.1:8795/ ，包括运营总览、12 款游戏目录、合作方与应用、规则与收益、局单与对账、版本与发布、开发者中心。所有示例操作明确标注本地状态，不会改变原游戏、App 余额或生产配置。

**可操作状态。** 支持分类/搜索/列表切换、完整设计详情和旧原型入口；应用创建校验和按 App 独立授权；不同人数与费率的分奖计算及 2v2 分配；98%/99% 数学候选选择；局单筛选、CSV 导出和未知结算查单演示；Node.js/Java/PHP 文档示例，以及成功、余额不足、超时、取消、重复结算的五种本地流程。

**玩法和资产。** [游戏目录](game-catalog.json)、[10 款规则册](game-rules-v1.md)、[逐款资产生产计划](asset-production-plan.md)、[验收矩阵](acceptance-matrix.md)。Jackaroo 使用本项目明确选定的规则变体；所有关键胜负、计分、平局、超时和掉线行为可作为后续实现基线。概念图尚未替代分层资产、3D 模型与动画制作。

**接入和资金。** [接入指南](integration-guide.md)、[主钱包协议](wallet-protocol.md)、[OpenAPI 3.1](openapi.json)、[签名测试向量](examples/signature-vector.json)、[架构决定](architecture-decisions.md)。18 条接口路径、40 个 schema 定义了两类服务器的职责，域名均为不可调用的占位。概率采用 authorize → accept → 固定结果 → settle；收到受理成功前不能开奖。

**独立技术预研。** 本机地址 http://127.0.0.1:8796/ ，四个程序化角色、真实 WebSocket 与服务端固定步进。1 用户＋3 明示脚本客户端供预览，另以四个独立浏览器客户端验证结果一致和重连。此页面是技术灰盒，不是最终美术游戏。完整证据见本目录外的 `../spikes/VALIDATION.md` 和 `../spikes/evidence/`，不作为手机、正式反作弊或生产承载量证明。

**验证口径。** `../review/contract-check.json` 是契约引用、12 款目录、整数示例和 HMAC 验证；`../review/ui-review.json` 是桌面 Chrome 的界面与交互检查。移动宽度截图仅为桌面浏览器缩放视口，不代表 Android/iOS 真机。最终构建通过；10 组界面与交互检查全部通过，未捕获浏览器异常为 0；360/390 px 视口检查无横向溢出。契约检查通过 18 条路径、40 个 schema、508 个引用及完整 HMAC 向量。
