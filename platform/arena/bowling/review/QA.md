# Bowling 本地验证

证据生成于 2026-09-19，macOS arm64 / Node 22.22.3 / 桌面 Google Chrome。引擎版本 `pvp-bowling-v1.0.0`，物理版本 `bowling-rigid-v1.0.0`；固定 60 Hz 权威物理，20 Hz 增量姿态回放。源文件 SHA-256 见 [engine-freeze.json](engine-freeze.json)。

## 规则、稳定性与性能

[规则测试](../rules-validation.tap) **19 / 19 通过**，包括三局全中与补投、28 分示例、第三局无递归奖励投球、非法输入、沟槽、同输入精确复现、JSON 恢复、准备超时、全员同 tick 弃权、截止时已受理球、有效完成后离线、轨迹不向对手重复传输，以及实体碰撞唤醒休眠瓶并连锁全中。四位玩家同一合法动作产生完全相同的权威轨迹。

修复了第三次准备超时恰好填完最后一局时逃避弃权的问题。回归明确覆盖：A 合法记录 `[10],[9]`，B 完成六次 0；A 随后连续三次超时，A 弃权、B 获胜。两位玩家同 tick 遇到该边界则作废，先前已经合法完成的成绩仍保留。

[物理矩阵](physics-matrix.json) **106 次合法输入、0 次 FAULT**。包含偏移 ±0.85 / 角度 ±0.20 / 力度 0.25 与 1 / 旋转 ±1 的全部 16 个角点，中心力度、旋转、口袋球路，以及固定随机流生成的 64 个偏心投球。32 次真实刚体碰撞获得全中；没有按目标分数改写结果。

| 指标 | 本次结果 |
| --- | ---: |
| 最长物理时间 | 9,800 ms |
| 单投计算中位数 | 124.83 ms |
| 单投计算 P95 | 281.25 ms |
| 单投计算最大值 | 512.63 ms |
| 四人 `engine.view` JSON 最大值 | 70,944 bytes |
| FAULT | 0 / 106 |

这是一台本机顺序模拟的观测值，不是容量承诺。同步计算的 512 ms 尾延迟仍会阻塞同进程其他请求；生产必须隔离物理工作池、限制并发并重新压测。矩阵不是全参数域的形式化证明；10 秒仍未稳定的真正物理异常继续进入故障恢复。

## 手机视口与交互

[UI 自动报告](ui-validation.json) 记录了真实浏览器与独立本地 HTTP 权威引擎往返。390 × 844 使用双人布局，360 × 844 使用四人布局；测试断言实际 view 的玩家数量，未知路径不会重建测试房间。两种尺寸均执行真实 pointer down / move / up 向前投球、等待服务器结果并检查无横向溢出和浏览器异常。另以默认投球按钮完成实体碰撞全中，断言 `STRIKE` 与 `win` 音效调用。

图像人工检查覆盖待机十瓶阵、球的旋转与前进、跟球近景、各瓶红环、实际倾倒姿态、计分格与全中演出。已压低白瓶高光，并加入正确输出色调映射；碰撞音效只跟随主要撞击段播放，避免末尾微接触持续触发声响。
