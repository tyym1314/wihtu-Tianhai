# 弹指棋手机输入回归

2026-09-28。仅修改 `board.mjs` 和 `CarromGame.jsx` 的输入生命周期和局部门控，未修改视觉、棋盘物理或规则。

- 置位、拉杆与瞄准跟踪同一主 pointerId 和服务器回合/shotId。第二触点、取消、失 capture、页面隐藏/失焦都会终止拖拽。
- 每帧及每次输入核对 canShoot、aiming 阶段、截止时钟、当前回合与 capture。即使状态短暂不可操作后又恢复，旧拖拽也不会继续改角度。
- 帮助面板开启时禁用出杆；发送前再次校验当前合法置位与时间，同步 pending 锁防重。

运行 `node tests/precision-touch-ui.mjs`。Chrome 7 项、WebKit 7 项检查通过，页面错误 0。原生第一指能正常调整瞄准；第二指后两指继续移动均产生 0 次角度更新；取消和临时非 aiming 状态后也不残留拖拽。新的一次点击仍正常瞄准。瞄准本身不发送 shot。
